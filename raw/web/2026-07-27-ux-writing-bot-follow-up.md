## Source summary

The article is a follow-up to an earlier UX-writing bot experiment. It focuses on why well-written reference documents can still be skipped by AI, and on revising reference material so the model can reliably retrieve and apply it. The durable theme is that documentation quality includes structure, discoverability, and machine-usable boundaries, not only human readability.

## Reusable evidence

- Reference content needs explicit structure and retrieval cues if an AI system is expected to use it.
- A good document can fail operationally when its rules are buried, ambiguous, or difficult to select at the right moment.
- Improving the reference layer can be more valuable than repeatedly adding prompt instructions.

## Limits

The source is an experience report about a UX-writing workflow, not a controlled evaluation of retrieval or model behavior.
