# 재무의 빗장을 풀어 데이터의 호수로 (Unlocking Finance to the Data Lake)

This article explores how Bucketplace’s **FP&A (Financial Planning & Analysis)** team transformed financial data from a restricted, retrospective report into a real-time decision-making tool for the entire company.

## Key Concepts
*   **The Nexus Data Lake:** A data lake that bridges ERP and operational data. It automatically converts operational data into accounting standards for the ERP and feeds processed financial data back to the field, filtered for security but rich in profitability metrics.
*   **Finance DA (Data Analyst):** A unique position at Bucketplace combining accounting expertise with data engineering. They design pipelines using AI to generate code drafts and schema mappings.
*   **AI Orchestration (FP&A Central):** An AI system where two "conductor" agents coordinate 18 specialized agents for cross-verification, report drafting, and anomaly detection.
*   **Unit Economics in Operations:** MD and SCM teams use shared dashboards to decide on item cancellations based on actual profitability (Contribution Margin) rather than just volume.
