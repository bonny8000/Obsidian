## Summary

Google for Developers documentation introducing **Natively Adaptive Interfaces (NAI)**: a design framework for embedding accessibility **into the core of multimodal AI agents** rather than adding it afterwards. The framing is that adaptive and interactive accessibility can be natively built in, so interfaces adapt across differing user abilities and contexts by construction.

## Core positions as stated

- **Accessibility as foundational, not supplementary** — not a compliance afterthought.
- **Multimodal integration** — built inside AI agents using **Gemini** and **Gemma** models.
- **Native adaptation** — adaptive and interactive accessibility built into the agent itself.
