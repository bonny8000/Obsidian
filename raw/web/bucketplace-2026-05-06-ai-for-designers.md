# 디자이너가 AI를 쓰는 법 : 더 빠르게 고민하고, 더 깊게 검증하기 (How Designers Use AI: Thinking Faster, Verifying Deeper)

Product Designer **Gongdee** shares how to use AI to eliminate workflow bottlenecks in the design process, focusing on validation and speed.

## Workflow Phases
*   **Phase 1: Rapid Drafts:** Using **Figma Make** for directions and **Claude Code** (via Figma MCP) to generate functional HTML prototypes within a single day.
*   **Phase 2: Automated UT (User Testing) Setup:** Using **Athena MCP** to pull real user data into HTML prototypes, reducing setup time from 2 hours to 15 minutes.
*   **Phase 3: Interactive Specs:** Creating prototypes where developers or QA can toggle conditions (e.g., coupons, shipping) in real-time to see UI changes, reducing clarification questions.
*   **Impact:** Draft work reduced from 3-4 days to half a day; improved cross-team communication quality.
