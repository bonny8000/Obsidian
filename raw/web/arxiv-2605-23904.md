## Abstract

Agent skills today are hand-crafted, generated one-shot, or evolved through loosely controlled self-revision — none of which behaves like a deep-learning optimizer for the skill, and none reliably improves over baseline performance.

SkillOpt treats skills as external state that can be trained systematically. It uses a separate optimizer model to convert scored rollouts into bounded text-space edits (add/delete/replace) on skill documents, accepting changes only when validation scores strictly improve.

## Core Mechanism

- **Textual learning-rate budget:** controls how aggressively edits are applied per epoch
- **Rejected-edit buffer:** stores failed edits to avoid re-trying them
- **Epoch-wise updates:** structured optimization rounds (analogous to weight-space training epochs)
- **Zero inference-time overhead:** at deployment, skills are plain text — no runtime cost

## Key Results

- Best or tied best performance across **all 52 tested configurations**
- Spans **6 benchmarks**, **7 language models**, **3 execution environments**
- On GPT-5.5: **+19.1 to +24.8 percentage point** improvement depending on execution method
- Skills transfer effectively across model scales and different deployment platforms

## Methodology

The optimizer model analyzes scored execution rollouts and proposes controlled text edits to skill documents. Edits are validated against held-out test sets before acceptance — mimicking the rigor of weight-space optimization but operating entirely in the text domain.

## Key Claims

- Treating skill documents as "external weights" trainable via a text-space optimizer is a novel and effective framing
- Validation-gated edits prevent regression (only strictly improving changes are accepted)
- The approach generalizes: skills trained on one model transfer to others
- Self-evolving skills outperform hand-crafted and one-shot generated alternatives across all tested conditions
