# The AI Design Guide — Curated Resource Directory for Agentic AI Design

**Author / Curator:** Romina Kavcic (also runs The Design System Guide, thedesignsystem.guide)
**Publisher:** The AI Design Guide (aidesign.guide) — landing page captured 2026-06-22

## Summary

The AI Design Guide is a curated, weekly-updated resource library aimed at designers building products with agentic AI and design-system automation. It is a living catalog/directory rather than a single article — the home page is an index pointing into guides, prompts, tools, a knowledge base, a dictionary, templates, comparisons, and a 158-entry design-systems directory. The tagline is "Agentic AI for designers," and the stated value is saving research hours via proven design-system automation, written "from real projects, not theory." The library is partly gated (login / pricing / "First Agentic Design Community"), and a weekly Substack newsletter (The DSG / Design, Systems, Growth) accompanies it. As of capture, the catalog advertises 87 guides, 33 prompts, 34 dictionary terms, 26 templates, and 9 learning paths (some section counts on the page vary between 87/33/34/26 and 15/21, reflecting frequent updates).

The content skews practical and tool-specific: deep guides on token pipelines, Figma MCP setup, Claude Code for design systems, and component audits; production prompts (design system health check, component spec generator, design critique) tested across Claude, ChatGPT, and Gemini; hands-on tool reviews (Claude, Cursor); and side-by-side comparisons (Style Dictionary vs Tokens Studio, Claude Code vs Cursor) explicitly "no affiliate links, no hedging." Recent guide titles indicate currency with the agentic-design moment — e.g., "Build Your Own MCP Server for Your Design System," "Claude Fable 5 for Designers," "Rolling Out AI Across a Design Team," "The AI-Assisted Accessibility Review," and "The Taste Stack" (project rules + local markdown + skills to teach AI your visual standards).

Several free interactive tools are the most concretely useful artifacts: Style Explorer (20 visual styles, one-click copy of CLAUDE.md rules), Tools.md Generator (creates a tools.md context file for Claude, Codex, Cursor, and coding agents), Trust Levels Playground (one finding rendered at five levels of agent autonomy, to "feel the difference"), Token Audit (50 token files compared), and Name Design Tokens (an interactive token-naming tool at namedesigntokens.guide). The design-systems directory tracks what companies like Netflix, Meta, Porsche, and Volvo actually ship, searchable with tokens, components, and docs, alongside trend reports and team interviews. Logos on the page claim 502+ designers from companies including Atlassian, Meta, Salesforce, Replit, Webflow, Decathlon, and others.

Treat this as a pointer/index and discovery surface, not as citable evidence for any specific claim. Its value to the wiki is as a curated entry point to designer-facing agentic-AI and design-system tooling — especially the free generators (Tools.md Generator, Style Explorer, Trust Levels Playground, Token Audit) which map directly onto design-system context-engineering work. Because it updates weekly and is partly paywalled, specific counts and titles will drift; re-check before relying on any number.
