# Datarize launches "AI Product Search" — vendor announcement

**Published:** 2026-07-24 · **Captured:** 2026-07-28
**Capture note:** **Vendor marketing material.** AI-written summary. No independent metrics; all claims are the vendor's. Full text not reproduced.

## Summary

Datarize, a Korean e-commerce personalization vendor, announced an AI-powered product search feature aimed at reducing purchase abandonment by making existing catalog items findable.

## Problem as framed by the vendor

Keyword-matching search fails when shoppers use synonyms, misspellings, spacing variants, or conversational descriptions. The vendor's position is that this loses sales on products that exist but are never surfaced.

## Technical approach as described

Rather than collecting large datasets, the system maps relationships between product-information fields with AI, giving semantic rather than lexical matching:

- Synonym recognition (스커트 ≡ 치마).
- Tolerance for spacing variation and typos.
- Contextual description interpretation (e.g. "환절기 걸치기 좋은 아우터" — outerwear good for layering in changing seasons).
- Auto-hiding out-of-stock items.
- Prioritizing high-performing and new products.

No architecture, model, or retrieval detail is given.

## Features listed

- Personalized search recommendations, up to 12 custom suggestions.
- AI-generated product summaries and review highlights.
- Related-product suggestions based on browsing history.
- Save / wishlist directly in search results.
- No-code customization of color, layout, and sizing via console.

## Availability

Limited to **fashion-category retailers on the Cafe24 platform** with existing Datarize subscriptions.

## Caveats

- Vendor marketing; no independent performance data, no A/B results, no baseline.
- No conversion, revenue, or search-success metrics of any kind are published in this announcement.
- Availability restricted by platform and category, so generalization is unsupported.
- Useful only as a **market signal** that semantic/AI search is being productized for mid-market Korean commerce — not as evidence about efficacy.
