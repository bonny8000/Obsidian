# How PMs Read the Market ⑥ — What's the Difference Between SaaS and Platforms?

**Original title (ko):** 「PM은 어떻게 시장을 읽는가 ⑥SaaS와 플랫폼은 무엇이 다른가」

## Summary

An explainer arguing that IT companies which look similar on the surface run on fundamentally different business models, and that a PM's first analytical move should be identifying which one they are in. The distinction drawn is **SaaS (selling software that solves an operational problem)** versus **platform (selling connections between parties)**.

## Framework

| Dimension | SaaS | Platform |
|---|---|---|
| Core value | Software functionality that solves a problem | Connections between users |
| Revenue model | Subscription fees | Transaction fees / advertising |
| Growth driver | Product quality and retention | Network effects |
| Key metrics | MRR, ARR, retention | GMV, MAU, transaction volume |
| Biggest risk | Customer churn | Network collapse |

## Key claims

- **SaaS strategy:** build a product good enough that users keep it long-term because of the efficiency gain.
- **Platform strategy:** build an ecosystem connecting multiple stakeholder groups; value emerges from the interactions, not the software.
- **PM roles diverge accordingly:** SaaS PMs optimize features; platform PMs design ecosystems.
- **Investor lenses differ:** SaaS demonstrates predictable recurring revenue; platforms show scalability with volatility risk.

## Company examples

- **SaaS:** Salesforce, Slack, Notion, Figma, Zoom.
- **Platform:** Airbnb, Uber, 당근마켓 (Karrot), Booking.com, NOL (Yanolja).
- **Travel-industry illustration:** hotel management software is SaaS; booking aggregators are platforms.

## Decision guidance

Before analyzing competitors or features, establish whether the business sells **connections** or **solves operational problems** — the answer changes which metrics matter and what "growth" means.

## Caveats

The post clarifies a clean binary but does not address hybrid models or businesses transitioning between the two. No original data; this is an explainer for a PM audience.
