## Source summary

The author describes an AI feature experiment in an audio live-streaming product. A first attempt used fixed greeting presets to increase chat, but clicks did not create meaningful DJ-user interaction. A second design used live chat context to generate questions that a DJ could respond to, while avoiding real-time speech transcription because of implementation burden, voice-data sensitivity, and cost. Chat conversion did not materially move, but ARPU was higher in the contextual-message group; the author reports that the effect remained after removing outliers and that the recovered value exceeded token cost.

## Reusable evidence

- Optimize for the user relationship or outcome, not only the proximate behavior a feature was designed to increase.
- Treat ARPU as an outcome requiring outlier checks and repeated observation, not as a single impressive average.
- Use context selectively: thresholds, caching, and per-user call limits can make AI features more useful and economically viable.
