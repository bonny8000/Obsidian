# Source 2: AI UX Writing Principles (Rapport Labs)
**URL:** https://blog.rapportlabs.kr/ai-ux-writing
**Source:** Rapport Labs Team Blog (Author: Jiyeon Hong)

## Summary
A case study on building an AI-powered UX writing system at Rapport Labs. The author details the creation of a Figma plugin that uses Claude and a Notion database to provide real-time copy inspection and generation, ensuring a consistent brand voice without a dedicated UX writer.

## Key Insights
- Startups lack dedicated UX writers; AI can fill the gap for consistency.
- Guidelines must be integrated into the workflow (e.g., Figma plugins) to be effective.
- Claude (Sonnet 3.5/4) + Case DB (Notion) proved reliable for strict adherence.
- "Vibe Coding" using AI (Cursor) allowed quick prototyping of internal tools.

## Concepts
- UX Writing TF
- AI Inspection Bot
- Vibe Coding
- Human-in-the-loop (AI suggests, Designer decides)
