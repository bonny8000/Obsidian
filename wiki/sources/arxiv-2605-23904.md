## Summary

SkillOpt frames agent skill documents as "external weights" that can be trained systematically. A separate optimizer model converts scored execution rollouts into bounded text-space edits (add/delete/replace operations) on skill documents. Edits are validation-gated: only changes that strictly improve held-out test scores are accepted. The system includes a rejected-edit buffer to avoid re-trying failed edits, epoch-wise update rounds analogous to gradient descent epochs, and a textual "learning-rate budget" controlling edit aggressiveness per epoch. At inference time, skills are plain text ??no runtime overhead.

## Key Claims

- Current approaches to agent skills (hand-crafted, one-shot generated, or loosely self-revised) do not behave like deep-learning optimizers and do not reliably improve over baseline.
- SkillOpt achieves best or tied-best performance across all 52 tested configurations.
- Results span 6 benchmarks, 7 language models, 3 execution environments.
- On GPT-5.5 specifically: +19.1 to +24.8 percentage point improvement depending on execution method.
- Skills trained on one model transfer effectively to other models and deployment platforms.
- The validation-gated acceptance mechanism prevents regression.
- Zero inference-time overhead: optimized skills are plain-text documents.
