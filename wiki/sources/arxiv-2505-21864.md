# DexUMI

## Citation

Xu, Mengda, et al. "DexUMI: Using Human Hand as the Universal Manipulation Interface for Dexterous Manipulation." arXiv:2505.21864, submitted 2025-05-28, revised 2025-10-02.

URL: https://arxiv.org/abs/2505.21864

Raw source card: `raw/web/arxiv-2505-21864.md`

## Summary

DexUMI uses the human hand as a universal interface for transferring dexterous manipulation skills to robot hands. It combines wearable hardware and visual software adaptation to reduce the gap between human hand demonstrations and robot hand execution.

## Key Claims

- A wearable hand exoskeleton can adapt human motion toward feasible robot hand motion.
- Replacing the human hand in video with robot hand inpainting can reduce the visual gap.
- Hardware and software adaptation are both used to bridge human-to-robot embodiment differences.
