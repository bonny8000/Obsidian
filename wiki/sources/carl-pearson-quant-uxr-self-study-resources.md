# Carl Pearson: Learn Quantitative UX Research

## Citation

Pearson, Carl J. "Learn Quantitative UX Research: Self-study resources." Carl J. Pearson, PhD, 2025-02-17.

URL: https://carljpearson.com/learn-quantitative-ux-research-self-study-resources/

Raw source card: `raw/web/carl-pearson-quant-uxr-self-study-resources-2025-02-17.md`

## Summary

Pearson provides a practical learning map for quantitative UX research. The central structure is a four-pillar model: statistics, surveys, programming, and research design. The guide is especially useful because it maps concrete books, blogs, and websites to those pillars.

## Key Claims

- Quant UXR learning is easier to plan when broken into explicit pillars rather than treated as one vague skill.
- Surveys should be treated as a core pillar because they are widely applicable in quant UXR roles.
- Research design deserves its own pillar because it governs bias, validity, and method fit.
- Programming should be learned through concrete analysis goals; SQL is a practical complement to R or Python.
- Advanced modeling is not the entry requirement for quant UXR; stronger basics in surveys, statistics, design, and analysis are the safer foundation.
