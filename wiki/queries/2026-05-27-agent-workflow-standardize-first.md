# Which agent workflows should Bonny standardize first: research, design review, prototype generation, or wiki maintenance?

## Short Answer
Wiki maintenance should come first, because it is the shared memory layer that makes all other agent workflows compounding. The sources consistently frame the LLM Wiki as the prerequisite knowledge base that guides every subsequent agentic task. Research automation and design review can follow once durable project context exists.
