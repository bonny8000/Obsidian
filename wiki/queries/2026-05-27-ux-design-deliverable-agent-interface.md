# What does a UX design deliverable look like when the "interface" is partly an agent?

## Short Answer
When the interface includes an agent, the deliverable expands beyond screen flows to include: (1) an agent behavior specification (what the agent can and cannot do, how it responds to ambiguous input, how it fails gracefully); (2) a conversation design sample with representative utterances and agent responses; (3) a human-control map showing when and how the user can override or redirect the agent; and (4) an evaluation framework defining what good and bad agent responses look like.
