# Egocentric Robot Learning

## Core Idea

This cluster tracks a research direction: using first-person human data to scale robot learning, especially manipulation, transfer, world modeling, and generalist robot policies.

## Working Interpretation

The research cluster is converging on a shared bottleneck: robot data is expensive, human data is abundant, but transfer requires alignment across body, vision, action, task, and evaluation protocol.
