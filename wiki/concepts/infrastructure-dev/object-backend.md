# Object Backend

## Summary
A data architecture where the primary storage and access layer is focused on discrete "Objects" (entities) and their relationships, rather than raw files or relational tables.

## Why it Matters
It shifts the focus from "writing notes" to "modeling information." For an LLM-Wiki, an object backend makes it easier for an AI to perform structured reasoning.

## Key Claims
- Objects are the "atoms" of the information system.
- Every piece of information belongs to a typed object with defined properties.
