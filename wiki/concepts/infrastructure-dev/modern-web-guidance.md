# Modern Web Guidance

## Summary

`modern-web-guidance` is a specialized tool and knowledge base for modern web development best practices. It provides actionable guides for implementing features using native web APIs (e.g., CSS `:has()`, View Transitions, Popover API) to ensure high performance, accessibility, and maintainability without unnecessary dependencies.

## Why It Matters

As web standards evolve rapidly, AI agents and human developers often rely on outdated patterns. This tool acts as a "living standard" that helps:
- **Minimize Technical Debt**: By prioritizing native browser features over heavy libraries.
- **Ensure Consistency**: Providing standardized implementation patterns for common UI/UX challenges.
- **Agent Empowerment**: Serving as a reliable source of truth for AI agents to generate modern, idiomatic code.

## Key Claims

- Prioritizes "Baseline" browser features to ensure compatibility and performance.
- Framework-agnostic guides that can be adapted to React, Vue, or Vanilla JS.
- Designed for both human developers and AI agents (CLI/JSON output).
- Supports localized and high-performance typography/UX patterns.

## Integration with AI Agents

The tool can be integrated into AI agent workflows as a "skill" or MCP server, allowing agents to:
1. **Search** for the most modern way to implement a feature.
2. **Retrieve** detailed guides and code snippets.
3. **Synthesize** the guidance with existing design systems or component libraries.
