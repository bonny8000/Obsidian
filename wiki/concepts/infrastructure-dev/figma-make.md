# Figma Make

## Summary
Figma Make is a suite of AI-powered features within the Figma design platform that automates repetitive design tasks, generates initial layouts from prompts, and bridges the gap between design and production.

## Key Features
- **Prompt-to-Layout:** Generating wireframes or UI components based on text descriptions.
- **Design System Mapping:** Automatically suggesting components from an existing design system to match a loose sketch or prompt.
- **Content Population:** Filling designs with realistic, contextually relevant data.

## Why it matters
It represents the "industrialization" of UI design. By automating the "Surface" and "Skeleton" planes (see [[concepts/ux-research/five-planes-of-ux|Five Planes of UX]]), it allows designers to spend more time on "Strategy" and "Scope"—the high-level user problems and product objectives.
