# HEART Framework

## Summary
The HEART framework was developed by Google's UX Research team (Kerry Rodden, Hilary Hutchinson, and Xin Fu) to help choose and define large-scale user experience metrics.

## The Metrics
- **Happiness:** Subjective measures of user satisfaction (e.g., NPS, ratings).
- **Engagement:** Level of user involvement (e.g., frequency of use, sessions per user).
- **Adoption:** New users starting to use a feature or product.
- **Retention:** Rate at which existing users keep coming back.
- **Task Success:** Efficiency, effectiveness, and error rate (e.g., time to complete, success rate).

## Implementation
Each HEART dimension is tracked using a **Goals-Signals-Metrics** process:
1. **Goals:** What is the high-level objective?
2. **Signals:** What user actions indicate success or failure?
3. **Metrics:** How do we quantify those signals?
