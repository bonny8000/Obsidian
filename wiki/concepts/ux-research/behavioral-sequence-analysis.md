# Behavioral Sequence Analysis

## Summary
Behavioral Sequence Analysis (BSA) is a quantitative method used to analyze the chronological order of user actions. It goes beyond simple task success rates to understand the *patterns* of behavior as users navigate an interface.

## Key Primitives
- **State Transition:** The movement from one user state (or screen) to another.
- **Sequence Mapping:** Visualizing the paths users take, often using Markov chains or sankey diagrams.
- **Anomalous Paths:** Identifying "loops" or "dead ends" where users get stuck.

## Why it matters
BSA helps identify the "happy path" versus the actual paths users take. It is particularly useful for optimizing multi-step workflows (like checkout or onboarding) and identifying hidden points of friction that aren't captured by single-point metrics.
