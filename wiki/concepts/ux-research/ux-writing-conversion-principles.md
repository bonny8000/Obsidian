# UX Writing Conversion Principles

## Summary
A set of practitioner-derived rules for writing high-converting UI copy (specifically for banners and CTAs) based on the premise that users scan interfaces in under 0.3 seconds. 

## Key Claims
Good UX writing for conversion operates on five multiplicative principles:
1. **Single Message**: Focus on one reason to click.
2. **Certain Reward**: Frame benefits around certainty rather than maximum possible value (context dependent).
3. **Light Verbs**: Use low-commitment action words (e.g., "Check", "View") to reduce [[wiki/concepts/ux-research/cta-friction|CTA Friction]].
4. **Specific Actions**: Tell the user exactly what is required (e.g., "Enter phone number" vs. "Enter info") to eliminate uncertainty.
5. **Familiar Words**: Avoid jargon and foreign loan words that introduce cognitive processing delays.

These principles act as multipliers: if any single factor is poor (e.g., highly unfamiliar vocabulary), the overall conversion rate will suffer regardless of the strength of the other factors.
