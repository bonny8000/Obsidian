# Cognitive Load

## Summary
Cognitive load is the amount of working-memory effort a task demands from a user. Interfaces, copy, and flows that demand more attention, memory, or reasoning than the user can comfortably spend produce friction, errors, and abandonment.

## Key Claims
- UX research that only tracks behavior ("who clicked what") misses the cognitive side — load, memory, and attention explain *why* users struggle. *(Medium: Cognitive Science and UX)*
- Cognitive effort is treated by the brain as a cost to be budgeted, not a free resource — users implicitly weigh effort against expected value before engaging. *(Cell TICS: cognitive effort)*
- Reducing load is a core conversion lever in UX writing: shorter sentences, familiar words, and one idea per line reduce the effort a call-to-action demands. *(Brunch: UX writing principles)*

## Why It Matters (for UX)
Load is the shared currency behind many UX heuristics: progressive disclosure, defaults, chunking, and plain language all work because they lower the effort a task demands. Treating load as a measurable budget — rather than a vague ideal — lets teams reason about where users will disengage.
