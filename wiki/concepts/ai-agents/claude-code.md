# Claude Code

## Summary

Claude Code is discussed in the transcript as Anthropic's coding-agent product surface for building, editing, reviewing, and coordinating software work.

## Why It Matters

For Bonny's wiki, Claude Code is relevant as an example of [[concepts/ai-agents/ai-coding-tools|AI Coding Tools]] becoming agentic work infrastructure: local terminal work, desktop preview workflows, remote/mobile task kickoff, code review, and multi-agent task management.

## Key Claims

- The CLI is framed as the earliest and most powerful product surface for coding tasks.
- Desktop is useful for graphical workflows and front-end preview.
- Web and mobile help users start tasks away from the local laptop.
- Claude Code's product evolution is tied to model capability, harness design, verification, and multiple parallel agent tasks.
