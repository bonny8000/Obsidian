# Vibe Coding

## Summary

Vibe Coding is a coding workflow where a human steers the intended behavior and direction while an AI coding agent writes, modifies, and verifies implementation details.

## Why It Matters

It changes the developer or designer's role from typing every line to setting direction, inspecting diffs, validating behavior, and correcting the agent's course.

## Key Claims

- Natural language can become a high-level control surface for code changes.
- The workflow requires tests, diffs, version control, and review because generated code can still be wrong.
- Vibe coding is strongest when paired with project context and clear coding standards.
