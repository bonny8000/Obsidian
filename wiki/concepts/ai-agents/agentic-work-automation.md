# Agentic Work Automation

## Summary

Agentic work automation uses AI agents to perform recurring knowledge-work tasks, produce artifacts, check their own work, and improve from feedback.

## Why It Matters

The transcript's practical advice is to identify repetitive work, automate it with AI, and iterate until the automation is reliable enough for daily use. This is the operating principle behind using the LLM Wiki as a living system rather than a static folder.

## Key Claims

- Good automation starts with repeated tasks the user already performs.
- A prototype that is never used daily creates little leverage.
- 90-95% reliable automation may still require too much manual review.
- The goal is to push workflows toward trustable, repeatable execution with clear verification.
