# 🦉 Athena MCP

**Athena MCP** is an internal Model Context Protocol (MCP) server at Bucketplace that allows AI agents to pull real, anonymized user data into design prototypes.

## Use Cases
- **Automated UT Setup:** Automatically populating design frames with a participant's actual "recently viewed products" or "order history."
- **Contextual Prototyping:** Creating [[concepts/ai-agents/interactive-specs|Interactive Specs]] that reflect realistic data states.

## Impact
- Reduced User Test (UT) setup time from **2 hours to 15 minutes**.
