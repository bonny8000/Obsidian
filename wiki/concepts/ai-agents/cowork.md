# Cowork

## Summary

Cowork is discussed in the transcript as an Anthropic agentic work product for non-code outputs such as decks, docs, meeting prep, customer briefs, inbox workflows, and knowledge synthesis.

## Why It Matters

Cowork represents an agent pattern where the output is a work artifact rather than source code. This is directly relevant to Obsidian-style knowledge systems because wiki maintenance, research synthesis, and meeting briefs are non-code outputs.

## Key Claims

- Cowork performs better when connected to relevant context sources such as Slack, Gmail, calendar, Drive, design templates, Salesforce, Gong, or Figma MCP.
- It can draft decks and briefs by synthesizing internal communications and source-of-truth documents.
- Human review remains necessary for outline, narrative, taste, and final quality.
- The product is positioned as complementary to Claude Code: use Claude Code when the output is code, and Cowork when the output is knowledge-work artifacts.
- **A non-coder can run a whole multi-agent operation through Cowork.** Vallaure operates a five-persona book-operations "team" defined in a single `CLAUDE.md` entirely through Cowork conversation, with "the only skill you need being able to have a human conversation" — a concrete low-floor instance of [[concepts/ai-agents/markdown-agent-orchestration|markdown agent orchestration]] ([[sources/christinevallaure-human-approach-agentic-ai|Vallaure, 2026]]).
